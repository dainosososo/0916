## 🚀 3. Projects 專案作品
- **專案名稱 / 研究主題：** NTUE 校園導覽 App
- **專案說明：** 專題為實作一款專用於國立臺北教育大學校內的校園導覽 APP。
  - **教室搜尋功能：** 建構即時搜尋系統，對使用者輸入處室名稱或教室編號進行關鍵字比對，將輸入內容統一格式化，縮小搜尋範圍提升搜尋準確度。可自動將地圖置中顯示目標建築並清除其他無關地標，彈出詳細資訊視窗與一鍵導覽按鈕。
  - **建築資訊視窗：** 透過先前蒐集資料，建構直觀資訊展示介面。使用者可點擊地圖上的建築地標查看樓層配置與處室簡介，並隨時執行導覽功能。
  - **效益總結：** 整合搜尋與導覽功能，提供便捷的校園資訊查詢體驗，大幅提升校園導航效率並節省尋找地點的時間。
- **使用技術：** Mapbox, JavaScript, HTML5, CSS3
- **GitHub Link：** 無 (Private Repo)
